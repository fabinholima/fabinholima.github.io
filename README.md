# Portfólio · fabinholima

Site pessoal: https://fabinholima.github.io

Projetos organizados por Química, Ciência e código, Aplicações e Linux. HTML, CSS e JavaScript sem dependências; todos os projetos continuam acessíveis sem JavaScript.

## Executar localmente

```sh
python3 -m http.server 8000
```

Abra http://localhost:8000.

## Atualizar

Edite os cartões em `index.html`, o visual em `style.css` e os filtros em `script.js`. Ao adicionar um projeto, atualize também a contagem inicial em `index.html`.

## Publicação

GitHub Pages, branch `main`, pasta `/ (root)`. Alterações nessa branch são publicadas automaticamente.
